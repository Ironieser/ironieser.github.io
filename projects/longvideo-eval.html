LongVideo-Eval is an open-source harness that evaluates long-video VLMs and efficiency methods on one accuracy-cost axis, with decoding, vision encoding and prefill all measured in one place.

A token count is not a cost

Long-video methods are usually compared by accuracy at a matched number of visual tokens. That leaves out most of what a long video costs. A keyframe selector may decode and score hundreds of candidate frames to keep sixteen. A token pruner may run the full vision encoder before discarding most of its output. Neither shows up in a token count, and each paper measures it differently, if at all. The harness fixes three things for every method.

One pipeline

Every method plugs into exactly one stage of a fixed chain and inherits everything else unchanged. Nothing else differs between two runs.

One budget

Every method in a comparison reads the same decoded frame pool under the same frame and token budget. No method quietly decodes more than another.

One cost record

Decoding, vision encoding, prefill and generation are recorded per sample by the harness. A method never reports its own cost.

Five stages, one of them yours

A run is a fixed chain. Pick a family to see which stage it implements and where its cost is paid.

1

Decode

video → frame pool

Metered: decode time, frames decoded

2

Select

pool → frames

Metered: selection time, such as scoring every frame

3

Encode

frames → visual tokens

Metered: frames encoded, patches into the vision tower

4

Prune

tokens → fewer tokens

Metered: tokens kept, pruning time

5

Generate

tokens + prompt → answer

Metered: visual tokens into the LLM, prefill, generated tokens

What gets written down for every sample

Each stage reports only its own increment and the harness adds them up, so nothing is counted twice. Every row of a result file carries the prediction and all of these.

Papers behind the harness

LongVideo-Eval grows out of a line of work from the same authors on efficient multimodal inference. If it is useful to you, please consider citing them.
